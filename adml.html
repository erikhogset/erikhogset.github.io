Automated Manufacturing Cell (ADML)

A team-built automated manufacturing system combining CNC machining, robotic handling, and BUMES-based cell control.

Manufacturing CNC Robotics Automation

System Demo

This project integrated machining, robotic part handling, and automated system control to demonstrate a functioning manufacturing cell in Boston University's Automated Design & Manufacturing Laboratory (ADML).

Problem

Modern manufacturing systems often combine machining, robotic handling, and automated coordination between machines. This project focused on developing a small-scale automated manufacturing cell capable of producing parts while coordinating machine operations, robot motion, and system-level logic.

The challenge involved integrating multiple subsystems — machining processes, robotic motion, and supervisory control — into a reliable automated workflow.

Design Goals

Manufacturing Goals

  • Develop reliable machining paths for part production
  • Ensure manufacturable tolerances and hole sizing
  • Coordinate machining operations with robotic handling

Automation Goals

  • Program robot waypoints for consistent part transfer
  • Develop cell-level control logic
  • Integrate machine operations into an automated sequence

My Role

This project was completed as part of a 6-person team, with most of the detailed implementation work carried out by me and my teammate Ranely. I took a leading role in turning the design into a working automated manufacturing system, focusing on machining setup, robot integration, and final BUMES programming.

  • Developed the machining toolpaths and manufacturing setup for the project components.
  • Helped define robot waypoints and contributed to robot programs used in the cell.
  • Wrote the final BUMES code coordinating system sequence and cell behavior.
  • Supported design iteration through tolerance adjustments and hole sizing decisions.
  • Led much of the system integration, debugging, and testing required to make the cell function reliably.

Manufacturing & Machining

Machining operations were used to produce the required components while ensuring dimensional accuracy and compatibility with the robotic handling system.

Robot Programming

Robotic handling was used to move parts between manufacturing stages. Waypoints were defined to ensure consistent pickup and placement of parts.

System Integration (BUMES)

The full manufacturing cell was coordinated using BUMES code, which defined the sequence of machine operations and robot movements.

This supervisory code ensured the machining system, robot motion, and part handling steps were executed in the correct order while maintaining safe and consistent operation.

Engineering Challenges

Manufacturing

  • Ensuring correct tolerances for robotic part handling
  • Balancing machining efficiency with part accuracy
  • Designing features compatible with the automation workflow

Automation

  • Synchronizing machining and robotic motion
  • Defining reliable robot waypoints
  • Debugging system-level automation behavior

Outcome

The final system demonstrated a working automated manufacturing cell capable of producing parts while coordinating machining operations, robotic handling, and system-level control logic.

The project strengthened my experience in manufacturing processes, automation systems, robot programming, and system integration.
