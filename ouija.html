Automated Electromechanical Ouija Board

Voice-controlled, AI-driven physical interface

Mechatronics Controls Fabrication AI Integration

Demo

The system moves a planchette across a laser-engraved board in response to voice-driven prompts.

What it does

  • Captures a spoken prompt (voice input)
  • Generates a response (AI)
  • Maps characters to board coordinates
  • Moves the planchette to spell out the answer

My role

  • Mechanical design of the X–Y motion system
  • Laser-cut enclosure + engraved board/planchette
  • Hardware integration (motors, controller, wiring)
  • Software pipeline from text → motion

Build Photos

Mechanical System (Internal)

Inside the enclosure is an X–Y gantry that translates commands into planar motion.

Laser Cutting Process

Board graphics and enclosure parts were produced using laser cutting/engraving.

Technical Summary

Hardware

  • X–Y planar motion system (belt-driven gantry)
  • Stepper motors + motion controller
  • Laser-cut enclosure (MDF/plywood)
  • Laser-engraved board + planchette

Software

  • Voice prompt → text
  • AI response generation
  • Character mapping to coordinate targets
  • Motion commands to trace spelling path
