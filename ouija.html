Automated Electromechanical Ouija Board

A mechatronic system that converts voice prompts and AI-generated text into physical motion across a laser-engraved board.

Mechatronics Motion Control Fabrication AI Integration

Demo

The system captures a spoken prompt, generates a response, maps characters to board coordinates, and moves a planchette to spell the response across the board using an X–Y gantry.

Problem

The goal of this project was to create a physical interface that could translate digital responses into visible mechanical motion. Instead of displaying text on a screen, the system uses a motion platform to physically spell responses across a Ouija-style board.

This required integrating voice input, AI text generation, coordinate mapping, and motion control into a single electromechanical system.

Design Goals

System Goals

  • Convert spoken prompts into physical output
  • Translate text responses into board coordinates
  • Maintain accurate planar motion across the board
  • Integrate electronics and motion hardware inside an enclosure

User Experience Goals

  • Create a theatrical and engaging interaction
  • Preserve the recognizable format of a Ouija board
  • Make the system visually polished rather than purely experimental
  • Ensure motion appears smooth and intentional

My Role

I led the design and development of the system, building the mechanical platform, writing the control software, and iterating on the overall system behavior. While teammates assisted with some supporting components, I was responsible for the core architecture and integration of the project.

  • Designed and implemented the complete motion-control software pipeline.
  • Developed the system logic for converting AI-generated text into motion paths.
  • Designed and fabricated the laser-cut board, enclosure, and planchette.
  • Built and integrated the X–Y gantry motion system and motor control hardware.
  • Iterated on system calibration, testing, and reliability.
  • Collaborated with teammates who produced several 3D-printed structural connectors used in the gantry frame.

Build Photos

Mechanical System

The motion platform uses a belt-driven X–Y gantry to translate digital commands into planar motion. Stepper motors drive the gantry along orthogonal axes, allowing the planchette to move precisely across the board.

Fabrication Process

The board graphics and enclosure panels were produced using laser cutting and engraving. This allowed precise board markings and rapid iteration of enclosure components.

Engineering Challenges

Motion Control

  • Translating text characters into board coordinates
  • Ensuring smooth motion between letters
  • Maintaining consistent motion speed and accuracy

System Integration

  • Coordinating voice input, AI output, and motion control
  • Packaging electronics and mechanical components in a compact enclosure
  • Calibrating the board geometry to match coordinate mapping

Outcome

The final system successfully demonstrated an electromechanical interface that converts digital responses into visible physical motion. The project combined motion control, fabrication, and software integration to create an interactive system that bridges digital AI responses and physical mechanical output.

This project strengthened my experience in mechatronics, motion systems, fabrication, and system-level engineering.
