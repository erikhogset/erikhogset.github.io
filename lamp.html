Sensor-Driven Smart Lamp

A motion-responsive lamp prototype integrating sensors, microcontroller control, and a motorized rotating head.

Electromechanical Design Sensors Controls Prototyping

Prototype Demonstration

Demonstration of the sensor-driven lamp prototype. Hand proximity is detected using an ultrasonic sensor, triggering a motorized rotation of the lamp head through a microcontroller-controlled actuation system.

Project Overview

This project explored the integration of sensing, actuation, and mechanical design to create an interactive lighting system. The lamp responds to user motion detected by a proximity sensor, automatically rotating the lamp head toward the detected direction.

The system combines mechanical design of the rotating head assembly with electronic control using a microcontroller, enabling the lamp to respond dynamically to environmental input.

Mechanical Design

Electronics & Sensors

Hardware

  • Ultrasonic proximity sensor
  • Microcontroller control system
  • Stepper / servo motor for rotation
  • Motor driver electronics

System Behavior

  • Detect user motion near the lamp
  • Translate sensor reading into control signal
  • Rotate lamp head toward detected direction
  • Return to idle position when no motion detected
